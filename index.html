✦ guia de instalação

eugrifo
do zero ao widget

Configure sua extensão de destaques pessoal e exiba-os em qualquer site — sem servidor, sem backend.

1

Crie o banco de dados (Repositório)

O seu repositório no GitHub funcionará como banco de dados. Recomendamos deixá-lo Público, pois assim o widget não precisa de senhas para exibir os destaques no seu site.

  1. Acesse o GitHub e clique em New repository.
  2. Dê um nome — ex: meus-highlights.
  3. Escolha Public (Mais fácil) ou Private (Mais seguro, exige configuração extra no passo 6).
  4. Marque "Add a README file" (Obrigatório para iniciar o repositório).
  5. Clique em Create repository.
2

Gere o Token Mestre (Para a Extensão)

A sua extensão precisa de permissão para escrever novos destaques no seu GitHub. Faremos isso gerando um Token Clássico (Seguro, pois ficará apenas no seu navegador local).

  1. Vá em Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. Clique em Generate new token (classic).
  3. Nome: eugrifo-extensao. Validade: No expiration.
  4. Em Select scopes, marque APENAS a caixinha principal chamada repo.
  5. Desça a página, gere o token e copie o código (começa com ghp_).
3

Instale a Extensão

Abra chrome://extensions, ative o Modo do desenvolvedor, clique em Carregar sem compactação e selecione a pasta do eugrifo.

4

Configure a Extensão

Clique no ícone ⚙️ da extensão. Na aba GitHub, cole o Token do Passo 2, seu nome de usuário e o nome do repositório (ex: meus-highlights).

5

Faça o primeiro Highlight

Selecione qualquer texto na internet, clique no ícone da extensão e salve. O arquivo JSON será gerado magicamente no seu GitHub!

6

Instale o Widget no seu Site

Copie o código abaixo e cole no HTML do seu site (WordPress, Vercel, Ghost, etc):

<div id="meus-grifos"></div>
<script
  src="https://cdn.jsdelivr.net/gh/od3zza/eugrifo@main/highlights-widget/widget.js"
  data-owner="seu-usuario"
  data-repo="meus-highlights"
  data-target="meus-grifos">
</script>
SEU REPOSITÓRIO É PRIVADO? LÉIA COM ATENÇÃO:

Se o seu repositório for privado, o script acima falhará. Você precisa adicionar uma linha extra: data-token="seu_token".

NUNCA use o token clássico (ghp_) do passo 2 aqui! Se você fizer isso, qualquer visitante do seu site poderá roubar o token e excluir seu GitHub. Você precisa criar um Token Granular, seguro para ficar exposto:
🔐 Como criar o Token Seguro (Fine-grained) para o Site
  1. Vá no GitHub em Developer settings → Personal access tokens → Fine-grained tokens.
  2. Clique em Generate new token. Nomeie como widget-site.
  3. Em Repository access, escolha "Only select repositories" e selecione o seu repositório meus-highlights.
  4. Em Permissions, abra "Repository permissions".
  5. Desça até a opção Contents e mude para Access: Read-only. (Deixe todo o resto vazio).
  6. Gere o token (ele começa com github_pat_). Copie e coloque no HTML do seu site: data-token="github_pat_...".

Dessa forma, mesmo que um hacker copie esse token do seu site, a única coisa que ele conseguirá fazer é ler os seus destaques — o que já é público de qualquer maneira.
