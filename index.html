✦ Instalação Rápida

eugrifo
em 6 passos

Crie seu próprio banco de dados de leitura no GitHub e exiba seus grifos no seu site. Sem custos, sem servidores.

1

O Banco de Dados (Repositório)

Seu repositório no GitHub funcionará como o seu banco de dados. Ele deve ser Público para que o widget consiga ler os grifos no seu site.

  1. Acesse o GitHub e clique em New repository.
  2. Nomeie como meus-highlights (ou outro nome de sua escolha).
  3. Marque a opção Public.
  4. Marque "Add a README file" (obrigatório para iniciar).
  5. Clique em Create repository.
2

A Chave de Acesso (Token)

A extensão precisa de uma chave de segurança para salvar os textos na sua conta. Vamos gerar um token que tem acesso exclusivo apenas ao repositório que você acabou de criar.

  1. No GitHub, vá em Settings > Developer settings.
  2. Acesse Personal access tokens > Fine-grained tokens e clique em Generate new token.
  3. Em Nome, digite eugrifo-extensao. Na Validade, escolha 1 ano (o máximo permitido).
  4. Em Repository access, escolha "Only select repositories" e selecione o repositório meus-highlights.
  5. Abra Repository permissions, procure por Contents e mude para Read and write.
  6. Desça a página, clique em Generate e copie o código (ele começa com github_pat_).
Guarde esse token! Você vai colá-lo dentro das configurações da extensão no Passo 4.
3

Instale a Extensão

  1. Baixe o arquivo .zip na página de Releases do GitHub e extraia a pasta no seu computador.
  2. Abra o Chrome e acesse chrome://extensions.
  3. Ative o Modo do desenvolvedor (no canto superior direito).
  4. Clique em Carregar sem compactação e selecione a pasta extraída.
4

Conecte tudo

Clique no ícone ⚙️ da extensão (no canto superior do navegador). Na aba "GitHub", cole o Token do Passo 2, seu Nome de Usuário e o Nome do Repositório. Salve e teste a conexão.

5

Faça seu primeiro Grifo

Selecione qualquer texto na internet, clique no ícone da extensão e salve! O arquivo que guarda seus dados será criado automaticamente lá no seu GitHub.

6

O Widget no seu Site (Opcional)

Quer exibir seus grifos no seu blog, portfólio ou site? Copie o código abaixo e cole no seu HTML (WordPress, Astro, Ghost, Vercel, etc):

<div id="meus-grifos"></div>
<script
  src="https://cdn.jsdelivr.net/gh/od3zza/eugrifo@main/highlights-widget/widget.js"
  data-owner="seu-usuario"
  data-repo="meus-highlights"
  data-target="meus-grifos">
</script>

O que você precisa saber

Dúvidas comuns sobre como o Eugrifo funciona nos bastidores.

Quem pode ver meus grifos?

O seu arquivo JSON de dados é público. Na prática, qualquer pessoa que consiga ver os highlights no seu site também pode vê-los visitando seu repositório no GitHub. Essa transparência é o que permite o sistema funcionar de graça e sem servidores.

Posso mudar o visual do widget no meu site?

O widget é inteligente e herda as fontes, tamanhos e cores automaticamente do tema do seu site para parecer nativo. Se você souber CSS, pode sobrescrever as variáveis raiz dele pelo código do seu próprio site.

Como funcionam as atualizações?

O código visual do widget é atualizado automaticamente para o seu site via nuvem. Já as melhorias na extensão serão notificadas diretamente no menu da extensão, e você poderá aplicar a atualização na aba "Aparência", além de ler as novidades na aba "Logs".
