✦ guia de instalação

eugrifo (v5.1)
passo a passo

Configure sua extensão de destaques pessoal e exiba-os em qualquer site — sem servidor, sem backend.

1

Crie o banco de dados (Repositório)

O seu repositório no GitHub funcionará como banco de dados dos highlights. Ele deve ser Público, permitindo que o widget leia os dados diretamente sem necessidade de autenticação.

  1. Acesse o GitHub e clique em New repository.
  2. Dê um nome — ex: meus-highlights.
  3. Escolha Public.
  4. Marque "Add a README file" (Obrigatório para iniciar o repositório).
  5. Clique em Create repository.
Importante: seus highlights ficarão armazenados em um arquivo JSON público. Isso significa que qualquer pessoa poderá visualizá-los tanto pelo seu site quanto diretamente no GitHub.
2

Gere o Token Mestre (Para a Extensão)

A sua extensão precisa de permissão para escrever novos destaques no seu GitHub. Faremos isso gerando um Token Clássico (Seguro, pois ficará apenas no seu navegador local).

  1. Vá em Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. Clique em Generate new token (classic).
  3. Nome: eugrifo-extensao. Validade: No expiration.
  4. Em Select scopes, marque APENAS a caixinha principal chamada repo.
  5. Desça a página, gere o token e copie o código (começa com ghp_).
3

Instale a Extensão

Abra chrome://extensions, ative o Modo do desenvolvedor, clique em Carregar sem compactação e selecione a pasta do eugrifo.

4

Configure a Extensão

Clique no ícone ⚙️ da extensão. Na aba GitHub, cole o Token do Passo 2, seu nome de usuário e o nome do repositório (ex: meus-highlights).

5

Faça o primeiro Highlight

Selecione qualquer texto na internet, clique no ícone da extensão e salve.

A extensão criará automaticamente um arquivo JSON dentro do seu repositório GitHub. Esse arquivo será utilizado como fonte de dados para exibir os highlights no seu site.

6

Instale o Widget no seu Site

Agora basta conectar o widget ao seu repositório para exibir os highlights automaticamente.

Copie o código abaixo e cole no HTML do seu site (WordPress, Vercel, Ghost, Astro, Hugo ou qualquer outro):

<div id="meus-grifos"></div>
<script
  src="https://cdn.jsdelivr.net/gh/od3zza/eugrifo@main/highlights-widget/widget.js"
  data-owner="seu-usuario"
  data-repo="meus-highlights"
  data-target="meus-grifos">
</script>
Como funciona?

O widget lê diretamente o arquivo JSON criado pela extensão no seu repositório GitHub e renderiza automaticamente os seus highlights no site.
⚠️ Sobre a visibilidade dos highlights

O EuGrifo utiliza um arquivo JSON público como fonte de dados.

Na prática, qualquer pessoa que consiga visualizar seus highlights no site também poderá visualizar exatamente o mesmo conteúdo diretamente no GitHub.

Isso simplifica a instalação, elimina a necessidade de servidores e permite que você mantenha controle total sobre seus próprios dados.

⚠️ Sobre o estilo visual dos highlights

O widget instalado no seu site possui um estilo visual básico pré-definido.

Porém, ele irá assumir características específicas — como cores, tipografias, botões — do estilo visual do seu site.

⚠️ Sobre atualizações

Eventualmente atualizações serão feitas para melhorar o widget e também a extensão.

As atualização do widget ficará visível na página onde você hospedar os destaques em seu site.

As atualizações da extensão serão notificadas na extensão e poderão ser conferidas e aplicadas em Configurações > Aparência > Tema da Extensão.

Você pode acompanhar os logs com atualizações na aba Log da extensão.
